## Matrix validation correction (2026-11-28)

The first all-output checker in commit 6f7f561 incorrectly assumed the synthetic weight index repeated every four output columns. The generator is wi(k,n) = (13k + 7n + kn mod 19) mod 4, so the true period is lcm(4,19)=76. This caused false `matrix readback mismatch` failures in every matrix/GEMV mode after the timed submissions; those failed runs produced no reportable latency numbers and do not indicate a Vulkan regression. Direct Vulkan compute/readback passed independently. The checker now computes 76 exact CPU reference columns per row and compares every output, with row/column/got/expected in any future mismatch diagnostic. Re-run the full probe before accepting any kernel timing or correctness result.
